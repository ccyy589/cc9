4. **正式投递**：确认后帮你走内部推荐通道提交
5. **进度同步**：每一步进展都会主动通知你
6. **面试跟进**：面试前后提供建议和信息支持
7. **结果反馈**：最终结果同步，入职后也可提供新人融入建议

## ❓ 常见问题

**Q：内推一定能通过吗？**
A：内推可以让你的简历获得更多关注和更快的流程，但最终结果取决于你的能力与岗位的匹配度。我会尽最大努力提供信息和帮助，但不保证录取。

**Q：可以同时内推多个岗位吗？**
A：建议优先投递一个最匹配的岗位。同时投递多个反而可能影响筛选效果，可以先评估最适合的方向。

**Q：已经网申过还能内推吗？**
A：通常在简历筛选阶段前可以走内推通道，已进入面试流程的无法更换。具体可以发信息帮你确认。

**Q：内推收费吗？**
A：全程免费。不会向候选人收取任何费用。
